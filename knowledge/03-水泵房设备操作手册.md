# 阳光新城生活水泵房设备操作手册

适用对象：阳光新城地库 B1 生活水泵房（服务 17 栋住宅楼、609 户，日供水约 850 m³），值班与巡检人员须持证上岗。

## 一、设备组成

| 编号 | 设备 | 主要参数 |
| --- | --- | --- |
| P1–P3 | 立式多级变频泵组 | 两用一备，Q=25 m³/h，H=90 m，P=11 kW |
| T1 | 气压罐 | 容积 1000 L，预充压力 0.28 MPa |
| W1 | 高位水箱 | 有效容积 60 m³，设于 13 号楼屋面 |
| L1/L2 | 液位计 | 高位水箱、地库蓄水池，4–20 mA 输出 |
| V1 | 变频控制柜 | 恒压供水，设定压力 0.40 MPa |

## 二、启停与切换操作

**启动（手动）**：确认蓄水池液位 ≥2.2 m → 打开泵前阀、泵后阀 → 控制柜切"手动" → 启动主泵 → 观察出口压力升至 0.40 MPa → 投自动。

**停止**：控制柜切"手动" → 停泵 → 关闭出口阀 → 复位报警。

**泵组切换**：每周一轮换运行，按 P1→P2→P3 顺序轮换；备用泵须保持自动备用状态，切换后 5 分钟内复核压力波动不超过 ±0.03 MPa。

## 三、日常巡检要点

| 项目 | 标准 | 频次 |
| --- | --- | --- |
| 出口压力 | **0.35–0.45 MPa** | 每 2 小时 |
| 高位水箱液位 | **2.2–3.0 m** | 每 2 小时 |
| 蓄水池液位 | ≥2.2 m | 每班 |
| 泵体温度 | ≤70 ℃ | 每班 |
| 振动/异响 | 无异响，振幅 ≤4.5 mm/s | 每班 |
| 阀门、法兰渗漏 | 无渗漏 | 每日 |
| 控制柜 | 无报警，指示灯正常 | 每日 |

巡检数据记入《水泵房运行记录表》，交接班双方签字。

## 四、常见故障与处置

| 故障 | 可能原因 | 处置 |
| --- | --- | --- |
| 压力不足 | 泵前阀未全开、叶轮磨损、压力传感器漂移、管道漏损 | 全开阀门→校核传感器→切换备用泵→排查庭院管网 |
| 水泵异响/振动 | 气蚀、轴承损坏、联轴器偏心、地脚松动 | 立即切泵、排气、紧固地脚并报修 |
| 液位报警 | 浮球卡滞、液位计故障、补水阀失效 | 现场核对实际液位，手动补水至 2.2 m 以上并检修 |
| 变频器跳闸 | 过载、缺相、散热不良 | 记录故障码，复位一次无效即停机报修 |

任一故障导致停水超过 30 分钟，须启动《给水管爆裂抢修预案》并通知 7 号楼、13 号楼等重点楼层居民。

## 五、安全注意事项

1. 进入泵房须双人作业，严禁单人操作电气设备。
2. 严禁无水空转，严禁带压拆装法兰。
3. 检修电气部分必须断电、验电、挂牌上锁。
4. 泵房保持通风、干燥，地面无积水；排水沟与集水坑每月清理一次。
5. 严禁在泵房内堆放杂物、动火，消防器材每月检查。
6. 发现水质异常（浑浊、异味）立即停供该路并取样送检。
